1. RunningSum Kahan kernel (closes the last-bits numerical divergence)
   - New src/ta/running-sum.ts: ports OakScriptJS's RunningSum arithmetic
     (MIT, attribution in JSDoc) as a session-scoped state class.
   - Rewrites math.sum, ta.sma, ta.variance, ta.stdev, ta.mfi to use the
     kernel. Outputs now match Pine bit-for-bit on cancellation-heavy
     windows, resync just below a power of two, series-length changes,
     na/+Infinity skipping. ta.stdev uses Pine's clamp
     `v > 0 ? sqrt(v) : 0` for tiny negative Kahan residues.
   - New tests/reference-pine-vectors-running-sum.test.ts: 12 tests
     transcribed from OakScriptJS's MIT tests/ta/running-sum.test.ts,
     pinning the kernel against actual PineScript outputs.
   - Promotes ta.sma, ta.ema, ta.variance, ta.stdev to `verified` in
     api-manifest/ta.yaml with the new vectors listed.

2. request.security_lower_tf gaps/lookahead semantics (was deferred)
   - lookahead=off now excludes the still-forming intrabar
     (bar.isClosed === false or close_time > callerCloseTime).
   - gaps=on returns an empty tuple when no intrabars match.
   - gaps=off carries forward the last intrabar's value as a single-
     element tuple (or [undefined] when no prior intrabar exists).
   - Refactored to keep cognitive complexity under 15.
   - New tests in tests/wave8-request-security.test.ts cover all
     combinations.
